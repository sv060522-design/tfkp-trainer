Открыть основной сайт

Перенос прежних отметок

Основной сайт теперь работает по адресу tfkp-trainer-zeta.vercel.app. Эта страница помогает забрать отметки, сохранённые в браузере на прежнем адресе.

Открой её в том браузере и на том устройстве, где отмечал задачи на старом сайте.

Импорт заменяет текущие отметки соответствующего раздела. Если на основном сайте уже есть важные отметки, сначала сохрани их через «Экспорт прогресса» или «Экспорт теории».

Задачи

Скопируй JSON ниже. На основном сайте открой «Прогресс», вставь его в поле JSON и нажми «Импорт прогресса».

Теория

Скопируй JSON ниже. На основном сайте открой раздел теории → «Прогресс теории», вставь его в поле «Резервная копия JSON» и нажми «Импорт теории».

Эта страница только читает прежние отметки. После переноса войди в один аккаунт на своих устройствах, чтобы прогресс синхронизировался.
