# ТФКП — тренажёр · ФЭФМ МФТИ

Статический тренажёр: https://tfkp-trainer.vercel.app/

## Каталог

500 задач, у каждой есть сверенное условие, ответ и полное решение:

- 447 семестровых и экзаменационных задач, включая все исходные варианты 1996/97–2009/10 и ранее подготовленные материалы 2014–2024 годов;
- 33 примера из С. И. Колесниковой, «ТФКП в задачах» (2016);
- 20 устных экзаменационных задач МФТИ 2007/2008.

Разборы объясняют выбор кольца сходимости, порядки нулей и полюсов, ориентацию контура, проверку сходимости, знак ветви и применение вычетов. Для задач с разрезами и конформными отображениями добавлены схемы. Каждая карточка содержит ссылку на конкретный источник и номер страницы/задачи.

72 неполных воспоминания об экзамене 2019 сохранены как исходные заметки `raw-memory`. Они не являются восстановленными условиями упражнений и не входят в число 500. В учебном каталоге нет задач без решения; проверка запрещает скрытые незавершённые упражнения.

## Прогресс

Старые идентификаторы и ключ `tfkp-trainer-progress-v2` сохранены. Отметки «Решено» и «В повторении» хранятся в `localStorage` этого браузера; обновление сайта их не сбрасывает. Экспорт создаёт JSON для резервной копии и переноса. Импорт проверяет структуру до изменения сохранённых данных. Некорректный JSON не стирает прежние отметки, а ошибка записи в хранилище показывается пользователю.

Прогресс не синхронизируется между устройствами автоматически: для переноса используется экспорт/импорт.

## Проверки

```bash
node scripts/check-catalog.js
```

Проверяет минимум 500 полных карточек, уникальные идентификаторы, отсутствие незавершённых упражнений, состав вариантов, источники, фильтры, схемы, чтение прежних отметок, импорт и обработку ошибок хранилища.

Для проверки всех TeX-формул нужен пакет `mathjax-full@3.2.2`, соответствующий зафиксированной версии CDN:

```bash
NODE_PATH=/path/to/node_modules node scripts/check-mathjax.js
```

Сложные интегралы проверены отдельно прямым численным интегрированием; значения ветвей — непрерывным отслеживанием аргумента от нормировки. Формулы с большими экспонентами проверены на эквивалентном меньшем контуре в области без полюсов, чтобы избежать потери точности.

## Локальный запуск

```bash
python3 -m http.server 5173
```

Открыть http://localhost:5173. Сборка не требуется.

## Добавление задач

Базовые записи находятся в `data/tasks.js`; дополнения — в `data/batches/`. `TFKP_MERGE_OVERRIDES` объединяет изменения полей и сохраняет другие данные карточки. Перед публикацией нужно сверить исходный PDF, добавить полное решение и выполнить проверки. **Старые `id` менять нельзя.**
