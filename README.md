# ТФКП — тренажёр · ФЭФМ МФТИ

Статический сайт-тренажёр по ТФКП. Его можно открыть локально двойным кликом по `index.html`, а в интернет выложить через GitHub + Vercel.

## Что внутри

- Исходная база из 499 записей задач/отзывов; опубликованы 180 карточек с вычитанным условием, ответом и решением.
- Семестровые варианты 1996/97–2014/15 и свежие файлы, которые были в папке `/mnt/data`.
- Реальные отзывы с экзамена 2019 из `ТФКП 2019 (Ответы).xlsx`.
- Полностью решены все четыре варианта 2014/2015, четыре осенних варианта 2006/2007 и четыре варианта 2006/2007 ФИВТ.
- Полностью решены исходники 2002/2003, 2003/2004 и 2007/2008; готов весь вариант 81 за 2008/2009.
- Прогресс, звёздочки и отметки «решено» через `localStorage`.
- Экспорт/импорт прогресса JSON-файлом.

## Важное ограничение

Старые PDF местами извлекаются с плохим OCR/кодировкой. Такие записи сохранены в исходной базе и скрыты из каталога, пока условие не вычитано и не добавлены ответ и решение. Перед публикацией нужно открыть исходный PDF и сверить формулу.

## Как добавлять задачи

Открой файл:

```text
data/tasks.js
```

Каждая задача — объект внутри массива `window.TFKP_TASKS`. Главное правило: **не менять старые `id`**, иначе у пользователей слетят отметки прогресса по этим задачам.

## Как запустить локально

Самый простой способ: открыть `index.html` в браузере.

Более правильно, через локальный сервер:

```bash
python -m http.server 5173
```

И открыть:

```text
http://localhost:5173
```
