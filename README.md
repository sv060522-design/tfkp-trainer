# ТФКП — тренажёр ФЭФМ МФТИ

https://tfkp-trainer.vercel.app/

500 реальных задач с условиями, ответами и решениями: 447 семестровых, 33 примера Колесниковой (2016), 20 устных задач МФТИ 2007/2008. Неполные воспоминания об экзамене не засчитаны упражнениями.

Ответ и решение скрыты по умолчанию. Есть подсказки, маршруты, краткие/полные разборы, 15 блоков метода, схемы, тематические тренировки и целые исторические варианты. Фильтры: несколько тем с AND, подтема, год, источник, тип, сложность, качество и личный статус. Все задачи доступны через «Показать ещё» и прямые ссылки #task=ID.

## Проверка качества

Независимые поля `statementVerification`, `answerVerification`, `solutionVerification` определяют зелёную отметку; `statementPretty` её не даёт. 499 условий source-verified; в одном исходнике не задан комплексный корень, и обе ветви подробно решены. Ответы проверены для всех 500 задач: 359 independently-verified, 141 numeric-verified. Все 500 решений reviewed.

Полный перечень изменений, распределения, найденные ошибки и методы проверки — в [отчёте](REVIEW-2026-10-03.md). Машинный отчёт всех карточек — [audit/review-2026-10-03.json](audit/review-2026-10-03.json).

## Прогресс

Старые ID и ключ `tfkp-trainer-progress-v2` сохранены. solved/starred безопасно читаются; новые статусы и повторение переживают перезагрузку и обновление сайта. Экспорт/импорт JSON переносит данные между браузерами. Невалидный импорт не стирает отметки; отказ хранилища показывается пользователю. Автоматической синхронизации между устройствами нет.

## Проверки

```bash
npm install
npm test
python3 -m pip install -r requirements-checks.txt
python3 scripts/check-expanded-math.py
python3 scripts/check-specific-math.py
python3 scripts/check-v23-v24-math.py
python3 scripts/check-branch-continuation.py
```

MathJax зафиксирован на 3.2.2, как в CDN сайта. Расширенный математический тест читает итоговый merge и не меняет данные. Он охватывает 301 карточку, включая все 80 задач с основной темой рядов; специальные наборы проверяют дополнительные случаи. Существенные/неизолированные особенности проверяются аналитически.

## Локальная разработка

```bash
python3 -m http.server 5173
```

Для проверки адаптивности используется `/qa/responsive.html?width=390` (также 768 и 1280). Это изолированное окно с настоящим приложением, тем же CSS и MathJax.

Данные загружаются в порядке index.html. Новые партии объединяются по полям через TFKP_MERGE_OVERRIDES; старые ID менять нельзя. Перед публикацией нужны источник, полный разбор и независимая проверка. Изменение проверенного текста должно обновить свидетельства и хэши, иначе catalog test падает.
