# Доработка тренажёра, 8 октября 2026

Сохранены все 500 задач, их ID, первичные условия и ссылки на источники. У каждой задачи есть условие, подробное решение и ответ. Решения и ответы по умолчанию закрыты.

## Ряды и объяснения

- Во всём итоговом каталоге и 15 блоках метода биномиальные коэффициенты записаны как `C_N^r`.
- Переписаны 76 рациональных задач на ряды, включая все 81 кольцо. Знаменатель факторизуется с проверкой корней и делением многочлена. Коэффициенты простых дробей вводятся как неизвестные; показаны общее тождество, раскрытие скобок, система по степеням, подстановка и проверка результата.
- Производная формула для коэффициентов простых дробей из этих разборов удалена. Формулы для вычетов остаются там, где нужны, и объясняются локальными рядами.
- При объединении рядов приведены замены индексов и нижних пределов. Первые несовпадающие степени и полиномиальная часть собираются отдельно; в хвосте у каждой степени один общий коэффициент.
- Для устной задачи 9 отдельно собраны коэффициенты косинуса, гиперболического синуса и дроби в обоих кольцах. Два ранее правильно объединённых экспоненциальных примера сохранены.
- В устной задаче 33 выведен коэффициент `C_{2n}^n/4^n`; сохранены ограничения совпадения суммы с нормированной ветвью.
- Дополнены 13 коротких разборов уравнений и вычетов: дискриминанты, полный список прообразов экспоненты, деление многочлена и вклады отдельных степеней.
- В методе об особых точках объяснено равенство `sin(π(k+1/n))=(-1)^k sin(π/n)` для целого k.

Стиль записи сверялся с конспектом А. Скубачевского: семинар 3 от 03.10.2023, страницы семинара 2–5 (PDF 18–21). Использованы порядок вычислений, метод неопределённых коэффициентов и сбор одинаковых степеней.

## Прогресс и список

Счётчики «в базе», «проверено», «решено», «не решено», «повторить», «не понял» открывают соответствующие подборки. При нажатии снимаются прежние тематические ограничения, поэтому счётчик и состав списка совпадают. Есть фильтр всех нерешённых задач и группировка по решённости, личному статусу или основной теме. Просмотр решения не считается решением задачи. Пагинация сохраняет доступ ко всему каталогу.

Ключ `tfkp-trainer-progress-v2` сохранён. Статусы и повторение переживают перезагрузку и обновление сайта. Экспорт/импорт JSON и защита от ошибочного импорта сохранены. Автоматической синхронизации между устройствами нет.

Кнопка «Сбросить решённые» переводит только решённые задачи в «Не решал», сохраняет повторение и остальные статусы, сначала записывает копию сбрасываемых отметок. Есть «Отменить сброс решённых». Отказ браузерного хранилища не выдаётся за успешный сброс. Ссылка с `?reset-solved=20261008` выполняет запрос пользователя один раз в браузере, где она открыта; повторное открытие не удаляет новый прогресс.

## Проверки

- `npm test`: целостность 500 задач, качество, фильтры, тренировки, 501-я тестовая задача и пагинация, старые отметки, импорт/экспорт, перезагрузка, счётчики и группировка, сброс с отменой, однократность ссылки и отказ хранилища. MathJax: **17 337 формул** без ошибок.
- `check-series-review.py`: **76 задач, 81 кольцо, 1 245 независимых коэффициентов Коши**. Проверены записанные системы, найденные коэффициенты, комплексные множители со скобками и итоговые формулы после сбора степеней.
- `check-expanded-math.py`: **301 различная задача, 306 проверок**: ряды, вещественные интегралы, контурная квадратура, интегралы с алгебраической ветвью.
- `check-contour-steps.py`: **32 исходных интегранта, 31 локальный вычет и 58 промежуточных коэффициентов**.
- `check-specific-math.py`: исправленные задачи, нормированные ветви, корни многочленов и элементарные уравнения, условия Коши–Римана, интегралы Френеля и Дирихле.

Численные проверки дополняют доказательства в решениях. Сохранены прежние раздельные статусы проверки: 499 условий сверены с источником; у одной задачи источник не задаёт выбор комплексного корня, и обе ветви разобраны с отметкой «требует проверки». Ответы и решения есть у всех 500 задач.

## Воспроизведение

```bash
npm install
npm test
python3 -m pip install -r requirements-checks.txt
python3 scripts/check-series-review.py
python3 scripts/check-expanded-math.py
python3 scripts/check-contour-steps.py
python3 scripts/check-specific-math.py
```

`build-series-review.py` воспроизводит пакет разборов на базовом каталоге, исключая свой собственный слой. Машинный список рядов и численные ошибки: `audit/series-review-2026-10-08.json`.
