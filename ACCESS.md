# ТФКП: если сайт не открывается

Основной адрес тренажёра: **https://tfkp-trainer-zeta.vercel.app/**.

Это бесплатный учебный проект: 500 задач МФТИ с подробными решениями, теория по темам и билетам, учебник Хасанова и самопроверка. Сайт остаётся на бесплатном хостинге Vercel.

## Доступность из России

В отдельных российских сетях соединение с Vercel не устанавливается: страница долго загружается или браузер показывает ошибку подключения. Доступность зависит от оператора и маршрута соединения; проблема не наблюдается во всех сетях России.

По наблюдениям автора, в сетях с этой проблемой тот же адрес открывается при подключении через VPN. Это техническое замечание о доступности конкретного учебного сайта. Здесь нет рекомендаций отдельных VPN-сервисов, ссылок на их установку или оплату.

Можно проверить страницу через другую сеть, например мобильный интернет вместо Wi-Fi. Если сайт не загружается полностью, повторять регистрацию или сбрасывать прогресс не нужно.

## Что происходит с прогрессом

Без входа отметки хранятся в том браузере, где вы работали. Другая сеть сама по себе не меняет сохранённые отметки; важно открывать основной адрес в прежнем профиле браузера. Другой браузер, приватное окно и другое устройство используют отдельное локальное хранилище.

При входе по нику и паролю отметки синхронизируются через серверное хранилище. Изменения, сделанные без связи, остаются в очереди этого браузера и отправляются после восстановления соединения. Не очищайте данные сайта, если в очереди есть неотправленные изменения. Для резервной копии используйте экспорт в разделе «Прогресс».

## Почему браузер не показывает эту справку вместо ошибки

Если соединение с хостингом не устанавливается, браузер не получает ни страницу, ни её скрипты. Поэтому сообщение внутри сайта в такой ситуации тоже не загрузится. Эта справка размещена отдельно на GitHub и доступна по прямой ссылке:

https://github.com/sv060522-design/tfkp-trainer/blob/main/ACCESS.md

Краткое замечание также добавлено в описание главной страницы для поисковых систем и предпросмотра ссылки. Поисковик самостоятельно выбирает текст сниппета, а изменения появляются после повторного обхода; отображение именно этой подсказки не гарантируется.
